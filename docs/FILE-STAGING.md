# 文件分享与暂存区

0.3.44 新增独立文件暂存区。收发文件需要组成员身份、双方的「剪贴板文件共享」许可，不需要连接键鼠，也不要求安卓 ADB / Root 就绪。双方均须更新到支持暂存区的版本。

## 使用方式

- Windows：首次正常启动 LanLink 后注册当前用户的文件 / 文件夹右键菜单「分享文件 · LanLink」。Windows 11 中可能位于「显示更多选项」。选中目标设备后立即传输到对方暂存区；设备操作菜单中的发送文件也进入暂存区。
- macOS：源码接入 Finder「服务 → 分享文件 · LanLink」。需要在 Mac 上重新构建；本次没有 Mac 编译或实机验证结果。
- Android：从其他应用选择文件并调用系统分享，选择 LanLink，再选择在线设备。支持一次分享多个文件；关闭或旋转界面不会主动取消已交给前台服务的发送任务。
- 电脑侧边栏「暂存文件」显示来源、时间、大小、文件数量和状态。接收完成可查看，或拖动「拖到文件夹以保存」到系统文件夹；系统报告成功复制后移除暂存条目。
- 手机 dock 的「控制中心」上方显示当前功能，下方横向排列「文件暂存区」「剪贴板」。进入时有文件默认显示暂存区，否则显示剪贴板。文件可查看，或通过系统文件 / 文件夹选择器保存到指定位置。

成功保存或拖出会移除接收端暂存条目及其缓存，发送方原文件保留。取消保存或保存失败保留条目。查看文件不移除条目；文件类型需要系统上有能打开它的应用。

## 拖动跨设备

电脑读取真实系统文件拖动的数据。拖到已配置的屏幕边缘并满足本端切换条件后，先切换键鼠，再给目标暂存区发送文件清单，不立即上传文件内容。目标显示「待传输」，由接收方点击「开始传输」。本机原来的系统拖动被取消，避免留下按键或拖动状态。

- 开始传输前源文件删除 / 改变，待传输条目自动消失。
- 本次鼠标控制会话结束、返回本机或断线时，尚未开始的条目撤回；接收方重启也不恢复这类临时条目。
- 点击开始后如仍排队，且会话在实际传输开始前结束，条目仍撤回。
- 已经取得源文件并开始传输的任务可继续，不因鼠标返回而撤回；失败后显示错误，可在来源在线且分享仍有效时重新传输。

源文件变化由接收端周期查询检测，撤回消息通过可靠控制通道发送，不保证界面在删除文件的瞬间刷新。物理 Explorer / Finder 拖动跨屏尚需实机联调。

## 存储、权限与传输

接收文件使用独立私有目录及持久化清单，临时文件完成校验后才标记「已接收」。接收本身不会修改系统剪贴板，也不申请输入控制权。分享记录仅供指定的目标成员读取，仍受组身份及剪贴板文件许可约束。

两端可用时文件走原生 QUIC 可靠流；数据线辅助或兼容场景走独立 AES-GCM 二进制 TCP 通道，192 KiB 分块 SHA-256 校验，保留旧分块回退。TCP 新增可协商的接收完成确认，发送方等接收方消费完整文件再断开，旧通道不强制要求该确认。画面和鼠标 Datagram 不用于文件内容。

每个接收端按队列传输暂存项目，不占满授权、输入和控制消息处理线程。传输沿用实时控制期间的限速预算。单个文件或文件夹总大小最多 2 GiB，文件夹最多 1000 个文件与目录；一次分享最多 100 个根项目，收件区最多 200 个项目。发送清单有效期为 7 天；保留原文件直至传输完成。路径穿越、重复路径、符号链接与特殊文件会被拒绝，文件夹的层级与空目录保留。

Android 分享文件先复制到软件私有发送缓存，再发出清单，避免依赖第三方应用的临时 URI 许可。成功接收确认后清理该发送缓存。传输中断不会把未完成文件当作已接收；重启后的未完成任务显示失败，由用户重新发起。

## 本次验证范围

Windows 原生界面、真实原生模块加载、桌面加密文件收发与安卓模拟器互通已验证。模拟器覆盖 QUIC / TCP 双向收发、八文件队列、系统分享目标选择、只读文件访问、中文路径 / 空目录、真实系统保存选择器、失败保留和成功移除。Mac 构建、实体手机、Explorer / Finder 实际拖入拖出及跨屏拖动还需实机验证。


## 0.3.46 补充

- 发送区明确显示等待、传输、完成、失败或取消；只有接收端确认才显示完成。失败或取消可重试，也可清除记录以释放分享额度。
- 接收任务支持取消；取消后清理部分文件，重试从头传输。取消排队项不会等待另一个大文件结束。
- 桌面“保存到…”使用完整新路径，拒绝覆盖同名文件；失败保留暂存记录，成功后才移出。Windows 拖出采用复制并保留暂存项，确认外部副本可用后再删除。
- 删除尚未保存的本机副本需要确认。清除未完成的发送记录会结束该分享，需要重新发送才能继续；发送端原文件保留。
- 桌面统一使用 `staging/state.json` 原子保存接收、发送和历史记录；首次启动兼容旧的 `index.json`/`outgoing.json`，新记录格式不保证降级兼容。
