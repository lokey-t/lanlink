# 鼠标手感

Windows 和 macOS 设置页的「无界鼠标 → 调整鼠标手感」显示本组所有设备。
主设备始终排在首位，其余在线设备在离线设备前。Android 等尚未支持的设备保留在列表中，并显示说明。

每台设备保留独立配置。在任意电脑上编辑后，配置会同步到组内其他电脑；离线设备重新连接后同步。
只有修改过的设备会提交，取消不会写入配置。默认保留既有体验：平滑滚动和反向滚轮关闭，灵敏度为 1.0×，不关闭加速度。

支持平滑滚动、反向滚轮和 0.2–3.0× 指针灵敏度。macOS 额外支持关闭鼠标加速度。
灵敏度适用于本机指针及无界鼠标的跨屏移动，远程桌面的绝对坐标定位保持屏幕坐标一致。
网络无界鼠标由主设备计算目标位置，目标设备不再重复放大。蓝牙输入由目标设备的本机事件处理生效。
macOS 不对连续滚动的触控板滚动事件再次平滑或反向。

没有增加管理员权限或修改系统全局鼠标偏好。使用现有的键鼠监听与注入权限。
在线设备缺少键鼠权限时，开启选项会打开该设备已有的权限引导，并提示用户到该设备操作。
离线设备可先保存，重新上线后在设置中显示当前权限状态。旧版本设备显示升级提示。

每台设备的设置带有独立版本和修改来源，同版本按来源排序，重复同步不再写盘或广播。
只接收当前组内成员的设置和修改来源，拒绝无效值、过远的未来版本以及错误组的配置。
更换组时旧配置不再生效，原生层恢复默认参数。原生处理不会永久修改系统鼠标参数，退出后停止处理。

## 参考

以下项目和文档用于了解实现方式，未复制项目源码：

- [LinearMouse](https://github.com/linearmouse/linearmouse)：按设备管理指针与滚动设置。
- [Input Leap](https://github.com/input-leap/input-leap)：跨设备键鼠事件和相对移动的处理。
- [Apple CGEventField](https://developer.apple.com/documentation/coregraphics/cgeventfield)：事件滚动与未加速指针位移字段。

已在 Apple Silicon Mac 上编译客户端和原生模块，渲染检查真实 SwiftUI 弹窗，并通过配置同步、断线重连、灵敏度处理及权限引导测试。
独立测试模块没有辅助功能与输入监控授权，因此未在该进程中注入实际物理鼠标操作；物理鼠标、触控板及蓝牙键鼠的实际手感仍需在已授权的应用内体验。
