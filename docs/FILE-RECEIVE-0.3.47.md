# 文件拖放与接收提示

Windows 和 macOS 的设备列表及布局画板支持把文件、文件夹拖到在线远端设备卡片。松开后，文件留在该设备的暂存区等待接受；本机原文件保留。移出卡片或取消拖动会撤回未接受的预览。

同组只保留最新的一次预传输，一次拖动可包含多个文件。新预览通过组内加密连接广播，旧预览的暂存条目和接收提示自动移除。迟到的旧预览、旧提示中的接受或拒绝操作不会影响新预览。已开始传输的任务继续运行，文件接收最多同时运行四个任务，其余排队；单个任务的取消不会中断其他任务。

- Windows：右下角独立浮窗，可直接接受或拒绝。
- macOS：右上角独立浮窗，可直接接受或拒绝。
- Android：系统文件通知，可直接接受或拒绝，点击通知正文打开控制中心的文件暂存区。需允许系统通知权限。

预览只交换文件清单，接受后才读取和传输文件内容。现有的组成员身份、文件分享授权、范围和文件大小检查继续适用。组内设备需全部更新，才能一致处理新的预览替换协议。

验证：真实加密连接的文件暂存及底层传输测试 37 项通过，包含三个设备之间的新预览替换、旧操作隔离、多文件并发和传输内容校验。Windows 原生界面验证了右下角位置、重复轮询、替换及撤回关闭；Android 15 临时模拟器验证了系统通知、拒绝操作、旧操作隔离和传输任务保留。macOS 本轮仅修改源码，未在 macOS 运行或编译。
