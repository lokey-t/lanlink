# QUIC 与 Datagram（0.3.40）

Windows、macOS 和 Android 共用 Rust / quiche 0.30.0 传输核心。桌面通过 Koffi 2.15.1 的 C ABI 调用，安卓通过 JNI 调用，不依赖 Node 的实验性 QUIC。

| 数据 | 通道 | 处理方式 |
| --- | --- | --- |
| 鼠标位置、相对移动 | Datagram | 序号过滤重复和乱序；累计相对位移补偿缺包 |
| 点击、滚轮、按键、文本、控制权 | 可靠双向流 | 操作附带最后的鼠标快照，执行前校正位置，保留输入顺序 |
| 剪贴板通知、权限请求 | 可靠双向流 | 沿用成员身份、设备授权和控制方向检查 |
| 文件 | 独立可靠双向流 | 每个 192 KiB 文件块使用一条流，原始二进制加 SHA-256 校验 |
| H.264 / JPEG 画面 | Datagram | 原生分包、重组；缺片不重传过期画面，失去参考链后请求关键帧 |
| 发现与初次配对 | 原有签名 UDP / 加密 TCP | 兼容没有 QUIC 能力的旧端 |

QUIC 票据和服务端证书 SHA-256 指纹通过已认证的主连接交换。票据只能使用一次，6 秒内有效，绑定该连接的组成员。TLS 私钥仅在内存生成，不写入磁盘；客户端发送票据和输入前校验证书指纹。不启用 0-RTT。主连接断开、成员移出或组解散会清理对应连接和票据，QUIC 不绕过首次授权。

可靠请求最多同时 32 条，输入队列最多 64 项。相邻的累计鼠标移动可合并，不能跨越点击、按键或控制权变化。旧连接的排队输入不会在新连接上执行。

0.3.42 起，带原始 `dx/dy` 的绝对位置消息也累计位移，并带 `raw:true` 标记。接收端保留归一化 `x/y` 供桌面绝对定位与手机触摸控制使用，同时恢复原始移动量供安卓虚拟外接鼠标使用。即使归一化位置已经被限制到边界，原始位移仍继续累计；不能通过受限位置差值推导系统鼠标位移。恢复量分成每轴不超过 1000 的输入，序号避免点击快照与随后到达的 Datagram 重复注入。单轴恢复量超过 32000 时丢弃过大的旧移动并更新基准，后续实时移动恢复，避免反复拒绝同一历史缺口。纯绝对位置与旧版本消息保持原有行为；修复需要两端同时更新。

补偿位置、可靠点击附带的位置快照以及其他远端注入移动不参与本机边缘切换。原生桌面区分注入和物理移动，补偿停在边缘时必须先离开再重新接近。跨屏光效的倒计时由主设备实际边缘判断发送，经当前控制会话、单调序号和输入授权校验；成功离开的闪光附在可靠释放请求中，避免乱序取消造成补闪或闪光被提前清除。

画面重组最多四帧、每帧最多 4 MiB，分片超过 150ms 清理。原生发送最多排两帧，按 QUIC 发送时间安排 UDP 包，并为鼠标保留 Datagram 队列空间。保留短参考链和动态码率反馈，不无限堆积旧帧。没有 FEC，缺失关键帧通过请求恢复，不能承诺任意丢包率下保持帧率。

## 回退与数据线

双方都声明 `quic:1` 才协商；原生库缺失或加载失败不声明该能力。建立失败保持原连接，运行中断清理按键状态并重新协商。已经发出的点击、按键不会在另一通道重复执行。视频恢复建立新会话，失败后冷却 30 秒，保留 WebRTC / TCP 回退。

已选中的 USB / 辅助输入连接继续优先使用原通道。ADB 端口转发承载 TCP，不能直接转发 QUIC UDP。这不是 QUIC 多路径实现，也不会把同一次点击同时发到网络与数据线。

文件按同次任务中已校验、已写入的字节偏移回退到原有通道，不提供跨重启持久化续传。共享画面时限制文件占用。

## 构建与验证范围

入口：`scripts/build-quic-windows.cmd`、`scripts/build-quic-android.cmd`、`scripts/build-quic-macos.sh`。Windows 使用 MSVC 静态运行库；安卓包含 ARM64、x86_64 与 NDK libc++，其他 ABI 没有 QUIC 库时使用兼容通道。Windows / Android 脚本优先使用工作区 `.tools` 工具链，否则使用本机已配置的 Rust、MSVC、CMake、NASM 和 libclang；安卓还需要 Ninja、对应的 Rust Android targets 和 NDK，可通过 `ANDROID_NDK_HOME` 指定 NDK。首次构建需要下载锁定依赖，缓存完整后可追加 `--offline`。macOS 需要本机 Rust、Xcode 命令行工具、CMake 和 libclang。

依赖由 `native/quic/Cargo.lock` 锁定，许可证见 `vendor/quic-notices`，安卓包包含相应通知。实测结果见 [验证记录](VALIDATION.md)。Windows / 安卓模拟器测试不代表 macOS 或小米实体手机已验证。
