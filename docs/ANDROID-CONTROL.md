# 手机控制与 ADB 授权（0.3.13）

安卓受控仅使用 Root / ADB 输入助手。已移除无障碍触控备用方案和 LanLink 输入法；没有助手时允许使用已具备的功能，例如单独授权后的屏幕查看。权限不足时手机弹窗说明缺少的权限，并提供设置入口。

## 首次设置与持久恢复

1. 手机与电脑加入同一组；手机在首次控制提示中允许该电脑操作。
2. 电脑安装 Android SDK Platform-Tools。可自动检测 Android Studio 安装的 SDK，也支持 PATH、ANDROID_HOME、ANDROID_SDK_ROOT、LANLINK_ADB。
3. 手机开启 USB 调试并连接电脑，在系统提示中信任该电脑。建议选择始终允许；厂商可能另有「USB 调试（安全设置）」。
4. 电脑发起桌面控制或边缘键鼠切换时，若手机输入助手未配置，会弹出带 SVG 动画的原生连接引导。通过加密组身份自动匹配已连接的手机，点击连接授权；就绪且手机首次同意后电脑自动继续；也可从左侧「安卓授权」进入。不会对所有连接的手机批量授权。
5. 成功后保存绑定。应用服务重启时助手自动重连，不需再次授权；手机重启后，电脑在已信任的 USB / 无线调试连接可用时自动启动助手。后台只恢复该设备公钥绑定的序列号，且再次检查组成员身份与手机给予的输入权限。
6. 可在手机非 Root 设置中解除本应用 ADB 授权并阻止自动恢复。这不撤销 Android 系统 USB 调试信任；撤销信任请在手机开发者选项操作。

这不是永久授予普通应用 INJECT_EVENTS。非 Root 手机重启后，若没有可用的调试连接，无法保证自动恢复。无线调试必须预先通过系统工具连接，本版不自动配对无线 ADB，也不开放网络调试端口。清除应用数据、重新安装或撤销调试信任可能需要重新设置。Root 手机可自行启动助手，本版不安装开机 Root 脚本。

首次授权成功后，每次手机重启，打开手机与电脑的 LanLink，用数据线连接已信任的电脑一次，即可自动恢复；等待恢复成功后可拔线。手机系统终止助手时，电脑需要可用的调试连接才能再次恢复。不会自动恢复已主动撤销的权限。ADB 助手就绪时可直接 H.264 串流；改用系统屏幕共享时仍需 Android 的录屏确认。

## 后台中断与 USB 插入提醒

安卓端在下次启动时核对上次服务运行记录。若上次在后台连接同组设备时异常结束，会提示检查省电白名单和自启动；已知的崩溃、内存不足、主动停止、应用更新及手机重启不会被误报成省电清理。Android 11 及以上优先读取系统进程退出记录，旧系统或缺少记录时明确显示原因未知。

引导按小米 / Redmi / POCO、华为 / 荣耀、OPPO / realme / 一加、vivo / iQOO、三星及其他机型显示设置步骤。设置页新增「后台运行与自启动」，可随时重新打开。厂商设置入口不可用时回退到应用信息或系统设置；应用会读取省电白名单和系统后台限制状态，自启动开关需用户在系统设置中确认。每次异常退出自动提醒一次，这些设置不能保证系统永不停止应用。

Mac、Windows 主控端在安卓连接中断时弹窗说明原因尚待确认；手机重连后，按上次运行的会话标识核对退出记录并更新说明。仅检测到后台限制时会说明“可能有关”，不会直接认定是省电杀进程；同一进程恢复网络连接会撤下待确认提示，主动切组和退出不会触发此提示。

电脑每隔约 10 秒检查 USB 调试设备。识别为本组且尚未完成授权的手机插入后，自动打开现有 ADB 引导；同一次插入关闭提示后不重复打扰，完成授权也不会自动发起控制。已有有效组身份及 USB 序列号绑定的手机可在系统显示未授权时提示；首次连接且系统 USB 调试尚未允许的未知手机无法读取组身份，需先在手机允许系统调试，再核验身份并显示引导。软件不会根据同型号或仅连接一台手机来猜测组归属。

系统参考：[进程退出记录](https://developer.android.com/reference/android/app/ApplicationExitInfo)、[后台限制状态](https://developer.android.com/reference/android/app/ActivityManager#isBackgroundRestricted())、[省电白名单状态](https://developer.android.com/reference/android/os/PowerManager#isIgnoringBatteryOptimizations(java.lang.String))。厂商自启动页面仍需在对应 ROM 上验证。

## 文字与触控板

- 电脑向安卓发送文字：通过允许的剪贴板写入，再由输入助手执行系统粘贴；目标应用须支持粘贴，不能保证密码框或禁止粘贴的应用可用。Android 后台剪贴板读取限制仍然存在。
- 手机控制电脑：上方屏幕支持平移和双指缩放，下方触控板控制鼠标，支持轻点、长按拖动、双指滚动和右键。底部键盘调用手机已有系统输入法，不需要安装 LanLink 输入法。
- 无控制权、控制请求未完成或旧电脑端不支持相对移动时显示原因与重试入口；不会静默丢弃触控板错误。电脑与手机应一起升级至 0.3.13。

## 组内权限详情

电脑左侧「本组设备权限」或设备菜单「设备详情与权限」显示本组所有设备，包括离线成员。分别展示键鼠、屏幕、剪贴板与文件、关机的应用开关、系统能力和该设备对当前电脑的允许情况。离线或不支持查询的旧版本显示未知，安卓关机标记不支持。状态约每 4 秒刷新；只读取状态，不自动打开权限。

## 助手通道

助手只连接手机本机环回地址。独立凭据与端口保存在应用私有数据中；采用每次连接的新随机挑战、双方 HMAC 证明和角色区分，不在网络传输中发送明文凭据。断线释放按键，重连后仍必须重新取得有效控制权才能输入。电脑固定启动 APK 内的 ShellAgent，不执行手机提供的任意命令。

系统参考：[Android ADB 文档](https://developer.android.com/tools/adb)。

## 跟随鼠标与小米输入诊断

手机控制电脑时，远程窗口画面下方提供「缩放画面跟随鼠标」开关，默认开启并持久保存。仅在放大后，根据电脑回传的真实位置平移画面，保留边缘余量；不会改变鼠标坐标。手动拖动 / 缩放画面时暂停，关闭后完全由手动调整。

小米 / HyperOS 的「USB 调试（安全设置）」与普通 USB 调试分开。遇到 INJECT_EVENTS / 模拟输入被禁止时，在手机开发者选项检查前者，按系统要求完成操作后重试；不可仅以助手心跳判定系统一定接受输入。参考 [scrcpy 官方设备要求](https://github.com/Genymobile/scrcpy/blob/master/README.md)。当前程序会保留反射调用的底层错误；出现错误时不再循环断开正常助手连接，手机弹出设置入口，桌面保留错误信息。

0.3.10 使用主键触摸事件和完整鼠标按钮事件以改善应用兼容性。已连接的小米 15（Android 16 / HyperOS 3）仅完成无点击诊断：未知键释放和鼠标悬停成功；取消事件被拒绝不等于缺少全部输入权限。尚未在该实机上验证新版完整点击 / 拖动 / 文本输入，不能据此宣称该型号已完全修复。


## 控制前准备与中断恢复（0.3.13）

远程窗口先请求同意并检查系统输入、屏幕共享，准备完成才启动画面；跨屏键鼠只使用原生虚拟鼠标，不申请悬浮窗权限。首次同意只开启选中的应用开关，实际操作才请求缺少的系统权限，键鼠操作不提前请求录屏。手机权限弹窗中已开启的项目显示「已授权」，缺少的项目提供设置入口。局域网发现和组内加密连接仍在后台进行，以便传递授权请求。

跨屏键鼠优先通过系统 `/dev/uinput` 创建会话内的虚拟外接鼠标和键盘，Android 因而使用系统鼠标光标和外接键盘路径；点击、拖动、滚轮、状态栏与控制中心走同一输入设备。ADB shell 或 Root 必须有该接口的实际权限；这只是本机虚拟 HID，蓝牙总线标识用于系统分类，并没有进行真实蓝牙配对。小米 15 的非 Root ADB shell 已确认能够注册虚拟键鼠。系统输入法的候选词、实体键盘设置和是否同时显示屏幕键盘由手机系统决定。

若系统拒绝注册虚拟键鼠，提示恢复 ADB / Root 助手，不再使用应用悬浮指针。结束控制或助手断线时释放所有按键并注销虚拟设备；远程窗口控制仍使用原有的精确触控，不显示手机指针。助手版本为 9，异步注入事件避免等待目标应用处理，输入请求通过单独队列按顺序执行。短暂重连有 12 秒宽限期，临时派发失败不会变成权限申请。

0.3.23 起移除手机设置中的结束屏幕共享时间选择入口；底层仍沿用已保存的延时，新安装默认为一分钟。网络意外断开也按此设置计时，ADB / Root 助手在线时可重新建立串流，无需系统录屏弹窗；仅系统录屏回退方式需要重新确认。重连会取消未到期的计时；主动结束、拒绝和另一方向控制冲突不会自动夺回控制。

电脑窗口可等比例缩放，手机旋转后按新画面比例调整。三键位于画面下方，鼠标进入底部区域时显示。


## Root 模式与整合后的授权页

电脑「安卓授权」显示本组手机的已就绪（ADB方式连接）、已就绪（Root方式连接）或未就绪状态。未就绪点击「连接授权」进入自动识别的连接引导。右下角「帮助其他组的设备ADB授权」进入「安卓设备ADB授权」页面，只选择本机连接的调试设备；手机需已打开 LanLink，不需加入本组，也不改变原组身份。后台状态查询不申请控制权限。

手机「设置 → 权限使用模式 → Root 模式」开启后，首次须在 Root 管理器允许 LanLink。仅在本机通道认证、确认助手 UID 为 0 后显示「已 Root 授权」。应用重启后按已保存选择恢复 Root 助手，不安装开机脚本，也不打开全局 ADB 调试。

Root 输入不依赖电脑 ADB。非 Root 在 ADB 助手就绪时使用同一直接采集路径；未连接助手时保留系统屏幕共享作为回退。ADB / Root 屏幕使用独立进程将主屏 Surface 直接送入 MediaCodec H.264 编码，按需启动，沿用加密视频通道、0.5–8 Mbps 动态码率和结束共享延时，不占用输入通道。最大长边 1600、目标 30 fps，无 B 帧；真实表现取决于设备与网络。横竖屏变化重建编码器，静止画面重新连接时主动请求关键帧。不申请受保护内容捕获能力；不再使用周期截图或 JPEG 回退，旧控制端需升级。

Root 模式自动尝试配置本应用的剪贴板 AppOps、相机和通知权限。厂商或 Root 策略拒绝时以实际系统状态为准，不能保证任意系统都可自动授予所有权限，后台剪贴板也可能仍受系统限制。关闭后停止 Root 输入和采集，恢复保存的普通协作开关、权限设置界面，并尝试还原 AppOps；相机 / 通知许可保留，可在系统设置撤销。每台设备的首次控制同意仍然有效。

## 手机设置与逐设备授权（0.3.13）

设置页依次为设备名称、权限使用模式、组设备授权管理、使用说明。

- 设备名称可编辑，保存后随设备信息同步给同组设备。
- Root / 非 Root 用分段按钮选择。Root 只有实际获得 UID 0 才显示「已授权」；被 Root 管理器拒绝时保留非 Root 设置。关闭 Root 恢复普通授权选项。
- 非 Root 的 ADB 状态区分「未授权」「已授权、等待助手恢复」；后者表示保存的绑定，不能等同当前可注入输入。点击未授权项显示电脑授权步骤；点击已授权项可解除本应用授权并阻止电脑自动恢复。重新开启需在手机点击「允许电脑授权」。此操作不会撤销系统 USB 调试信任。
- 组设备授权管理包含在线与已配对的离线设备，分别设置键鼠、屏幕、剪贴板 / 文件。撤销立即终止对应输入或屏幕会话；其他设备不受影响，选择在重启后保留。
- 手机主动解除 ADB 后，电脑连接引导切换为手机确认动画，手机显示“恢复 ADB 授权”弹窗；仅点击允许后才能恢复配置，电脑不能替手机批准。

Root 管理器本身的许可需在对应管理器撤销；应用中的「解除」停止 LanLink 的 Root 模式，不冒充撤销系统级许可。Root 自动配置、SELinux 策略及内部显示接口在不同厂商 ROM 上仍需验证。
