# 本组设备权限

桌面权限页按设备排列，使用键鼠控制、屏幕查看、剪贴板与文件、远程关机四列矢量图标。图标悬停显示功能和状态；左键、右键或键盘菜单键打开权限菜单。

- 绿色和勾号：应用、系统、访问授权均已就绪。
- 红色和感叹号：需要完成系统授权。
- 灰色和减号：应用开关或此设备的访问授权已禁用。
- 无法读取和不支持分别显示问号及“不支持”，不会误报就绪。离线设备不提供开启操作。

菜单显示目标设备、功能、应用状态、系统状态和访问范围。本机行的开关控制本机功能总开关；其他设备行的开关控制本机对该设备的访问权限。原有“此设备使用本机”的授权管理保留在菜单的独立入口中。

未就绪时，“一键开启”在所点击的设备打开对应权限的引导。本机只在选择其他设备时显示切换观看设备的动画提醒。系统授权需要在目标设备操作，打开引导本身不会授予权限。已禁用的远程访问重新开启时也需要目标设备确认，不能从请求端绕过禁用设置。

引导带请求标识和有效期，旧弹窗不能关闭后来的请求。Android 接收端复用现有输入、屏幕、剪贴板引导；Windows 和 macOS 使用聚焦到所选功能的引导。完成设置后通过权限刷新更新图标状态。

SVG 源文件位于 `assets/icons/permissions/`。原生界面使用相同坐标体系的矢量路径渲染，避免位图缩放模糊。切换设备动画遵循系统减少动画的偏好。

验证：Windows 原生自测覆盖图标矩阵、左右键菜单、本机引导、切换设备提醒、开关保存及刷新焦点；Node 测试覆盖权限状态、跨设备消息路由、禁用恢复和请求失效；Android 编译与引导生命周期探针验证接收逻辑。macOS 界面需要在 Mac 上运行原生验证。
