# 实机验收

至少准备 Windows、Mac、Android 各一台，连接可互通的私人局域网。
真实关机测试前先保存工作。每项记录系统版本、分辨率、权限和结果。

- 已认证组内设备首次打开远控、读取剪贴板或请求文件，不出现逐设备确认；应用开关或系统权限未就绪仍显示对应引导。显式禁用仅影响指定设备；撤销后立即释放输入并持续拒绝，主动请求恢复时才显示确认。
- 同时启动不同位置的新版 Mac 应用，只出现已有主窗口，不产生第二个服务；旧版先运行时新版唤起旧窗口。
- 两电脑、两 Android 同组：A 控手机一、B 控手机二时输入与画面互不串设备；竞争同一手机只有一个输入来源；多电脑查看同一手机，关闭一个画面不影响其他查看者。
- 手机助手已在 A 电脑启动后拔线，B 电脑不安装 ADB 也可经局域网控制；手机重启后提示恢复助手，不能仅凭保存授权显示可用。
- 远控窗口从手机一切换手机二，标题、画面和输入都对应手机二；旧窗口迟到的结束通知不释放新会话。
- 模拟弱网延迟、丢包与低带宽，检查鼠标频率、积压与画面码率降低；网络恢复后缓慢回升，点击不回跳，断线不重放历史按键。
- 桌面目标按屏幕尺寸打开；手机为竖向窗口，超出主机工作区时按比例缩小。三键分别返回、主页、最近任务；ADB / Root 模式分别测试。
- 被控设备缺少系统权限时显示入口，授权返回后对应行显示「已授权」；已有权限不再要求重复开启。手机录屏会话结束后重新申请本次权限。
- 桌面新组四项操作默认开启；旧组开关保留。自启动默认不注册；手动开关后重登系统检查启动 / 不启动，并确认保留原组。Mac 要求批准登录项时有系统设置入口。

- 手机端设备 / 设置切换不弹窗；横向设备列表可滚动；离线设备不出现可执行的控制按钮；大字体、横竖屏和系统导航栏下无关键操作遮挡。
- 手机明确关闭远程输入或撤销 ADB / Root 权限后，电脑请求控制：显示对应恢复引导；电脑收到失败信息，不能取得控制权。首次仅缺少助手时，不额外要求手机端应用确认，系统调试或 Root 要求仍须完成。
- 点击开发者选项入口能进入相应系统设置；返回后状态刷新。未完成系统授权时仅打开应用开关仍不可控制。
- 手机未授权屏幕录制时，电脑请求画面：出现本次共享授权入口；取消后不共享，允许后对方重试可取画面。
- 连续重试不刷屏；暂不允许后保持冷却；断开设备和更换组后不再保留旧请求。通知被系统关闭时，打开应用仍可查看有效请求。
- 设备配对页首次为二维码骨架；查看/隐藏、倒计时、刷新、加入组、相册与相机识别均可操作。

- 添加设备初始显示二维码骨架，点击后才显示；八位数字与刷新进度直接可见。加入组在当前界面展开输入框，支持前导零、粘贴及非数字拒绝。
- 等待 60 秒二维码和数字码一起更新；关闭、过期或成功配对后旧码不能再次使用；错误码不得变更组。
- Windows/Android 双向数字码、二维码配对及 Mac 实机互通；同网段广播受限、找不到设备、连续错误时提示清晰，可重新输入。
- 点击设备/设置只切换主内容；设置不弹窗，导航不丢草稿；名称校验错误直接显示在设置页，保存期间字段暂时禁用。
- 设备菜单背景随所在位置采样并模糊，前景文字清晰；Windows 支持时侧栏/顶部能透出桌面材质，关闭透明或不支持时仍可读。
- 主窗口、设备菜单、子菜单、设置、配对、确认和远程窗口采用同一圆角样式；标题栏拖动、双击最大化、边缘缩放与关闭操作正常。
- 紧凑窗口下设备气泡能横向滚动，布局卡片文字可读；键盘 Tab / Space 可操作开关，菜单子项可展开。
- 桌面双击软件直接显示窗口；关闭后托盘继续运行、返回本机输入；托盘恢复及退出正常。
- 顶部气泡横向滚动；点击气泡与画布设备出现同一操作菜单，没有独立共享入口。
- 拖动到四个方位后吸附并自动保存；已有布局设备交换，新设备替换该方向；重启仍保留布局。
- 设备离线后气泡和原布局保留，远程控制/粘贴/发送文件/关机不可点；重连恢复。
- 不支持透明效果或关闭系统透明时，背景仍清晰，文字可读；高 DPI 缩放无按钮截断。
- 发送文件选择器取消无副作用；目标未授权、输入焦点不支持文件粘贴、传输失败时显示实际错误。
- 远程窗口失去焦点或关闭后释放控制；等比例画面黑边不得导致坐标错位。
- 两台不同身份的设备不可建立控制连接；通过八位数字码配对后能自动发现，重启仍保持组。
- 安卓拍照/选择图片识别二维码，内容填入八位数字码框，确认加入后连接。
- 重启客户端保持身份与本地设置；离开/回到局域网自动断开/重连。
- 开启/关闭目标端每种权限，检查拒绝提示与即时释放行为。
- 在主机四个边缘分别配置设备，停留不足时间不切换，达到阈值只切换一次。
- 目标对侧边缘返回主机，Ctrl+Alt+F12 紧急返回。
- 键鼠切换期间断网/结束主服务进程，确认主机恢复输入、目标释放修饰键。
- 左/右/中键、滚轮、拖动、双击、Ctrl/Command 组合键、Shift 选区、中文文本。
- 复制中文文本、空文本、小文件、超过单块的大文件、同名文件、零字节文件。
- A 复制 → B 粘贴；B 复制 → 返回 A 粘贴；A 复制 → B 操作 → C 粘贴。
- 源文件被修改、断网、空间不足、剪贴板权限撤销时，应显示失败并不留下半成品。
- Windows 资源管理器与 macOS Finder 文件粘贴保持原文件名。
- 安卓文件管理器/聊天应用分别测试 URI 文件粘贴；不支持时应允许手动分享文件。
- 两个控制者同时请求输入，只有一个成功；关闭远程窗口释放控制。
- Android ADB 助手、Root 助手分别验收；确认不再注册无障碍服务或 LanLink 输入法；无权限不得宣称可用。
- Android 结束屏幕共享、旋转、休眠唤醒、进入受保护应用时画面行为。
- 远程关机 30 秒倒计时，本机取消、另一设备取消；撤销关机权限后不执行。
- 最后在保存所有文件后进行一次真实 Windows / Mac 关机验证。

当前版本的主显示器、JPEG 帧率、文件夹需 ZIP、无前向保密等限制不得当作通过项。

## 0.3.8 全组解散与配对

- A/B/C 为一组，C 离线。A 输入另一组的错误或过期码，应保留 A/B/C；取消确认同样保留。
- A 成功加入 D 的组后，B 在线退出并清除历史，A 与 D 连接。C 上线遇到 A 或 B 后退出；A 已换组或正常重启仍能发送旧组解散通知。
- 原组二维码再次输入不解散自身组；篡改通知签名、其他组通知、已移除成员的通知均拒绝。
- 安卓上方显示扫码图标和「点击扫码」，下面是手动输入与从图片选择；下方配对码和刷新进度直接可见，二维码默认隐藏。
- 未授权相机时提供系统权限提示；拒绝后可返回手输或图片识别。旋转、低亮度、不同屏幕密度和真实相机需实机验证。
